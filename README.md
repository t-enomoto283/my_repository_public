## Repository

### `work.sql`

実務で使用していたSQL処理を、社外公開可能な形に匿名化・一般化して再構成したものです。
複数のデータソースを組み合わせ、データの加工・集計・分析用データの作成を行う処理をまとめています。

主な内容：
* 外部データの取り込み
* 複数テーブルのJOIN
* 条件によるデータ抽出
* 集計処理
* CTEを利用した段階的なデータ加工
* URL等のデータ正規化
* 複数データソースの統合
* 分析用データセットの作成
* ランキング・スコアリング処理

※実際の顧客情報・社名・サービス名・URL・実データ等は含めず、社外公開用に名称・値・構造等を一般化しています。

### `study.py`

Pythonの学習過程で作成したデータ処理コードです。
主に、SQLで行ってきたデータ処理をPython / pandasでも実装しながら、データ加工やデータ品質管理に必要な考え方を学習しています。

主な内容：
* CSVデータの読み込み・出力
* 列の追加・データ加工
* `groupby()` による集計
* `sort_values()` による並び替え
* `merge()` によるデータ結合
* 結合条件の `validate`
* `indicator` を利用したデータ差分の検出
* データ品質チェック
* 関数化
* ERROR / WARNING / OK の判定
* ログ出力
* チェック結果のCSV出力

`データ結合 → 結合条件の検証 → 差分検出 → データ品質チェック → 後続処理`
という流れを意識して学習しています。
